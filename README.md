# Blog API (Django REST Framework)

REST API для блога с поддержкой постов, комментариев, токен-аутентификации, пагинации и документации Swagger.

## Стек технологий
- Python 3.13
- Django & Django REST Framework
- TokenAuthentication (`rest_framework.authtoken`)
- Swagger / OpenAPI (`drf-yasg`)
- SQLite
